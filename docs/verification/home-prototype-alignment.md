# 首页愿望与快捷卡片还原

2026-11-12，依据用户提供的图二和 `prototype/cheer-next/style.css` 修正原生 macOS 开发版。

- 删除愿望页底部“已有金额 + 创建后新增预估收入……最多添加 3 个”的整段说明；数量校验仍在保存入口生效。
- 首页恢复“我的小盼头 / 管理愿望 ↗”标题行；愿望改为左侧耳机图标、右侧名称/金额/进度、末端箭头的横向布局。首页不再显示管理页的剩余金额及编辑删除按钮。
- 增加“给自己充个电”分组和两张等宽功能卡片；卡片沿用原型的98点高度、12点间距、13点内边距、9点圆角及 `#f2f6ef` 浅绿底，包含图标、标题和辅助说明。
- 首页颜色复用原型语义值：主文字 `#263c32`、次要文字 `#708078`、进度 `#3e6951`、轨道 `#e3e9e1`；兼容原有深色主题。保留用户的玻璃及染色设置。
- 所有入口仍是原生 NSButton，金额隐藏时同步清除愿望摘要的辅助功能值和悬停提示里的金额；未修改工资计算、愿望持久化和木鱼动画。
