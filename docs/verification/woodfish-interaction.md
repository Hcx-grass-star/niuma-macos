# 木鱼动态交互

2026-11-12，原生 macOS 开发版。将原先完整 PNG 的整体缩放改为独立鱼身、木槌与命中反馈。

- 木槌抬起、落下、接触、回弹归位，一次摆动约 560 毫秒；接触约在 150 毫秒处，此时才增加功德并播放已启用的音效。
- 命中时鱼身压缩轻震、接触点出现短暂涟漪，“功德 +1”上浮淡出。首页仍使用完整小图标，交互页使用拆分后的 PNG 图层。
- 回弹期间可再次敲击，从当前木槌姿态继续；接触前的密集输入合并，避免积压一串动画和计数。
- 手动与每 1.5 秒的自动敲击共用一套过程。切页、关闭、离开及自动模式转为午休时，取消未接触的敲击和画面反馈；静止时没有动画刷新计时器。
- 系统开启“减少动态效果”时省略摆动、震动与上浮，保留文字淡入淡出。
