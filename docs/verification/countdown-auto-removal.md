# 倒计时到期自动删除验证

日期：2026-11-10。范围：原生 macOS 与 Tauri 共用前端。工作提醒属于同分支此前改动。

## 已实现规则

启用的固定日期倒计时在到期后自动删除，包括退出应用期间已过期的事件；关闭项保留，循环下班仍寻找下一班。完成的主事件被删除后回到自动选择，全部完成时面板倒计时区域收起、菜单栏不再展示倒计时文字。保存草稿时同样清理过期事件，避免旧草稿恢复完成项。

隐藏面板时复用唯一调度器等待最近固定目标，不逐秒刷新；配置发生删除时才写入。写入失败保留旧配置并显示错误。

## 验证证据

- 修改实现前，Swift 与 JavaScript 新用例因缺少清理接口失败。
- `npm run test:core`：到期前 1 毫秒保留、精确到期删除、主事件回退、JSON 重载、循环下班、关闭项保护通过。
- `swift run --disable-automatic-resolution NiumaIntegrationTests`：真实隔离目录保存重载、边界、偏好保留及既有收入集成验证通过。
- `bash scripts/test-countdown-ui.sh`：真实 AppKit 单调度器到期删除与磁盘回读、菜单栏回退、启动过期清理、最后一条消失，以及原有宽度、隐私和编辑器保存验证通过。
- ego-browser 在独立本地 HTTP 源验证：5 秒固定倒计时从摘要消失，剩余事件保留，主事件 ID 清空；重新加载后仍不恢复。全部完成时摘要区域隐藏。模拟 `localStorage.setItem` 配额错误后原记录保留且出现删除失败提示；恢复存储后再次刷新成功清理。

## 验证范围限制

浏览器验证覆盖 Tauri 共用前端，不等于 Tauri WebView 或 Windows 真机验收。本轮未重新发布、安装或替换正式应用，未修改用户的正式工资和倒计时数据。
