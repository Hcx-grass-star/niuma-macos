# 原生面板外观验证

日期：2026-11-06。范围：Swift/AppKit macOS 应用，不增加 iPhone/iPad 工程，也不修改 Tauri/Windows 界面。

## 用户行为

- “设置 → 面板外观”提供原生液态玻璃开关、跟随系统/浅色/深色和可选 sRGB 染色。
- 玻璃默认关闭、主题默认跟随系统、染色默认关闭；缺少外观字段的旧设置使用同样默认值。
- 保存后应用到收入面板，深浅外观同时用于设置窗口；取消修改不会写入外观草稿。普通背景保留圆角并使用轻微染色。
- macOS 26 起使用 NSGlassEffectView，业务布局放入其 contentView；较旧系统或系统要求降低透明度、提高对比度时保留普通背景。
- 玻璃只存在于展开的收入视图内。相同配置刷新不会重建材质；配置和辅助功能通知驱动材质变化，不增加轮询或计时任务。

## 已执行的验证

- 先添加真实 JSON → SettingsStore → 重载检查，修复前外观被丢弃，对应集成用例失败。证据：`build/panel-appearance-core-red.log`。
- `node scripts/test-updates.mjs`：16 组 Swift 收入、外观配置和真实本地 HTTP 更新检查通过；包含旧配置默认值、染色保存、非法 RGB 拒绝且不覆盖原配置、工资和收入不变。证据：`build/panel-appearance-core-green.log`。
- `npm run test:core`：共享 JS 收入测试通过。
- `NIUMA_UI_TRACE=1 bash scripts/test-native-ui.sh --appearance-config` 最终通过：通过真实设置控件保存和取消，核对实际存储、再次打开的控件值、深浅外观、原生玻璃类型/contentView/圆角/颜色、关闭后弱引用释放和普通背景深浅色透明四角。证据：`build/panel-appearance-native.log`。
- 采用隔离测试包、临时工资与更新偏好。两次测试脚本崩溃留下的临时配置和独立偏好已清理；未修改正式应用工资配置、自启动设置或正式安装包。

## 资源与验证边界

最终外观配置检查的 physical footprint 点位为：初始 18.81 MB、设置保存后玻璃面板 41.47 MB、收起玻璃后 41.45 MB，生命周期峰值 45.04 MB，均为十进制 MB。玻璃前已加载设置窗口，不能据此直接计算玻璃相对普通背景的额外开销。对象弱引用证明释放，但系统和分配器缓存仍可能保留页面，不能保证后台始终低于 30 MB。

普通背景的持续采样和菜单栏回归运行曾因真实失焦通知导致面板提前关闭而失败；这些区间不是有效的可见面板资源样本，不用于宣称性能达标。未取得完整的普通/玻璃稳定 CPU 对比。可在保持焦点的环境中执行 `bash scripts/test-native-ui.sh --panel-resources`，增加 `--glass-enabled` 则测试玻璃。

外观脚本中一次把“取消修改”按钮名称写成“取消”导致解包失败，另一次在设置未出现时解包失败；已改为正确按钮名称与明确失败诊断，最终外观链路通过。未将这些失败描述为应用产品崩溃。

当前没有可用的原生 computer-use 交互工具，因此这些是 AppKit 控件动作和实际对象验证，不是系统鼠标端到端验收；没有对真实桌面后的折射效果、原生颜色选择面板操作或 macOS 13–25 真机回退作视觉验收。SDK 已对 macOS 26 API 使用可用性保护。
