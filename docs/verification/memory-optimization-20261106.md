# 内存与 CPU 优化验证（2026-11-06）

已降低常用收入面板的内存和重复计算成本；后台始终低于 30 MB 的目标尚未全部达到。

本轮在独立工作目录 `codex/memory-under-30mb` 中实现，基于 0.3.1 源码。原工作目录及未跟踪节假日文件保留。没有替换 `/Applications/牛马上班.app`。工作目录同时出现的构建环境标识及非正式包自启动隔离改动予以保留，并非本轮性能优化的结论。

## 改动

- 收入面板改用按需创建的原生 NSPanel，关闭时释放内容控制器；保留菜单入口、设置、隐私、Esc 关闭和失焦收起路径。
- 复用主线程金额格式化器；仅在需要时更新菜单标题、字体、隐私图标与布局尺寸。
- 排班计数按引擎缓存，最多 32 项；缓存键包含排班及节假日开关，不保存工资或收入历史。时间环境变化时重建引擎。
- 未开启全国安排或缺失年份时按完整周计数；全国安排存在时仍遵守逐日覆盖。
- 窗口关闭后一次性请求分配器归还空闲页；不增加常驻回收轮询。设置表单使用传统滚动条。
- 未采用独立 UI 进程方案；未保留数值输入编辑器的无收益试验。

## 测量口径

本机 Apple Silicon、macOS 27.2；内核 `ri_phys_footprint`。本表 MB 为十进制 1,000,000 字节，原采样 JSON 中 MiB 为 1,048,576 字节。仅统计被测进程，不等同于活动监视器的进程组总数。测试通过真实 AppDelegate、AppKit 菜单和窗口运行，工资与更新偏好使用独立临时目录；自动网络检查关闭。探针包环境明确为 test，未覆盖正式包登录项状态查询的额外成本。

| 模式 | 本次短时内存 |
| --- | ---: |
| 初始后台，菜单栏显示当前金额 | 19.55 MB |
| 收入面板展开 | 25.63 MB |
| 收入面板收起 | 25.66 MB |
| 设置展开 | 45.66 MB |
| 设置关闭后的短时点 | 42.93 MB |
| 设置关闭后连续 30.20 秒最高值 | 44.17 MB |

上述 30 秒窗口平均 CPU 为 0.0558%（单核满载 100%）。后台测试驱动器仍每秒唤醒，不能将该数值视作生产进程零额外开销的精确结果。初始后台、收入面板和设置展开的本次样本满足 30/50 MB 对应预算；设置关闭后的后台仍不满足 30 MB。窗口与控制器弱引用均验证已释放，但这一事实不足以将所有剩余内存直接归因于某一个系统缓存。

这不是每种模式预热 60 秒、采样 600 秒的正式验收，也未覆盖 8 小时运行、实际系统键盘/鼠标事件、全部 macOS 版本、Intel 实机、更新下载和安装时的资源峰值。原生日志中的 Esc 与失焦检查调用正式处理路径，不是物理键盘或真实跨应用点击的证明。

原始记录：`native-ui-memory-20261106.log`、`resource-memory-optimized-30s.json`。探针包没有 NiumaSourceHash，因此 JSON 未绑定最终应用指纹；不能据此声称最终应用包完成了相同的全部资源验收。

## 计算耗时与功能验证

300 个相邻时刻、节假日开关开启、相同输入：

```text
reuse=false; 300 evaluations: 0.2754669166606618 seconds
reuse=true; 300 evaluations: 0.07724479166063247 seconds
PASS: exact Decimal results match
```

复用引擎后的本次计算耗时下降约 72%，这是计算微基准，不是整机或应用 CPU 降幅。

- `node scripts/test-updates.mjs`：15 组收入、排班、跨夜跨月、年度边界、配置变更、缓存容量淘汰、构建环境及真实本地 HTTP 更新检查通过。
- `bash scripts/test-native-ui.sh`：菜单、收入面板再次打开、关闭与失焦处理、窗口/控制器释放、设置取消及人民币格式通过。资源超预算不会被功能 PASS 掩盖。
- 安装文件集成：覆盖、回滚、版本及身份校验、篡改拒绝与旧副本清理通过；没有对用户已安装应用执行这些测试。
- `bash scripts/build-app.sh`：arm64 + x86_64 应用构建与临时签名验证通过；未作公证。
- 最终本地应用源指纹：`115837e302c83a61f49411e59372fafcaef8d643c089eb00d58a8b76a4159ec0`。

## 复验

```bash
node scripts/test-updates.mjs
bash scripts/test-native-ui.sh
# 延长探针至 90 秒，便于另一个终端按输出 PID 采样；测试退出后清理自己的配置与临时包。
NIUMA_MEMORY_INSPECT=1 bash scripts/test-native-ui.sh
# 对实际应用的 PID 单独做稳定窗口测量。
xcrun swift scripts/measure-resources.swift <PID> 600 build/resource-check.json
```

最终构建位于 `build/牛马上班.app`。目前是开发构建，须先退出旧版再打开，避免单实例逻辑激活旧应用。正式应用、登录项和用户工资配置未替换。
