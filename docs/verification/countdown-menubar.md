# 倒计时与菜单栏验证

日期：2026-11-06。范围：当前工作区 Swift 原生实现、JavaScript 核心和浏览器前端。本报告不代表 Windows 或 Tauri 原生安装包验收通过。

## 自动验证

- `npm run test:core`：原收入计算与新倒计时通过。覆盖 JSON 重载、跨夜、周末、到达、关闭项、数量限制、重复标识、系统时间重新求差、夏令时失败隔离、收入边界、隐藏停止及分钟/秒级调度。
- `swift run --disable-automatic-resolution NiumaIntegrationTests`：原 10 组收入、新倒计时真实文件保存重载和更新检查通过；无效配置不覆盖旧文件。
- `npm run test:updates`：JavaScript 和 Swift 真实本地 HTTP 更新回归通过。
- `bash scripts/test-countdown-ui.sh`：真实 AppKit 状态栏项目 60/120/240 pt 宽度、隐藏金额继续展示倒计时、仅图标无刷新 Timer、编辑器保存和退出释放通过。测试注入临时配置目录和独立 UserDefaults，不改用户工资。
- `bash scripts/build-app.sh`：arm64 + x86_64 通用应用构建和临时签名验证通过。工具链有既有缺失库搜索路径与 Intel 兼容库警告；未验证 Intel 真机、公证或公开发布。

## 浏览器操作

使用 ego-browser 在本地隔离 HTTP 源实际操作：未填写工资时新增并自定义标题、选主事件、保存 95 pt、重载恢复；新增下班并保存工资，显示双事件；保存 60/180 pt；241 pt 被表单阻止且保留旧配置；金额隐藏不影响倒计时。390×620 视口无横向溢出，修复添加按钮换行。

对前端注入测试用 Tauri 桥后，验证传出的 `update_tray_display` 文本与完整提示；隐藏窗口且选择仅图标时，收入/倒计时 `render` 定时任务为零。此处为桥接模拟，不能证明 Rust、系统托盘或最小化事件已在真机通过。

## 开发阶段资源采样

对象是独立 AppKit 集成测试二进制，注入隔离配置，面板关闭且隐藏工资；一条两小时内固定事件。启动时先执行宽度和编辑器测试后进入常驻，使用现有内核 physical footprint 和单核 CPU 累计时间采样工具。重新采样前已预热超过 60 秒，窗口为 60 秒；不是正式要求的 600 秒或 8 小时稳定性验收。

样本二进制 SHA-256：`258e9259075e00ca6d630496988587a25ac270f0513639b1d278b56126fb444f`。它包含本次刷新与菜单栏实现，后续编辑器选项同步及重置文案等小修未对这个样本重复编译；最终构建另行通过。JSON 的 `sourceHash` 为空，因为被测对象是测试二进制而非正式应用包。
