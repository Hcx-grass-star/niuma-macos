# 工作提醒与状态文案验证

日期：2026-11-10。范围：原生 macOS 菜单栏应用的工作节点提醒、收入面板状态文案和旧配置兼容。

## 行为

- 设置中新增“提醒上班、休息和下班”，默认关闭。
- 开启后，应用运行期间按当前有效排班提醒上班开始、非计薪休息开始、休息结束和下班。
- 通知正文不包含工资、当前已赚、本月或本年金额。
- 同一边界只发送一次；应用重启或休眠后不会把已经错过的边界补发。
- 关闭提醒、清除设置或保存新排班后，旧的等待边界立即失效。
- 收入面板顶部和鼓励文案会解释“距离上班、休息结束或今天已下班”等状态；节假日和调休原因继续沿用收入引擎结果。

本轮通知实现面向原生 macOS 运行中的菜单栏应用；没有在真实用户通知权限被拒绝、系统锁屏后实际唤醒、Intel 设备和长时间连续运行环境中完成实机验收。权限被拒绝时收入计算和面板继续可用。
