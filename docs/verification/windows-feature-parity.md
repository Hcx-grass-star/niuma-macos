# Windows 功能对齐验证

日期：2026-11-13。范围：Tauri 前端与共享收入核心；本次未生成 Windows 安装包。

## 已对齐

- 收入页保留当前、本月、本年预估收入、金额隐藏、倒计时、托盘、自动启动和更新入口。
- 新增收入、战报、愿望、木鱼四页导航。
- 战报使用页面和窗口离开/返回信号，满两分钟且存在计薪收入时生成最近一条战报；通知正文不含工资、金额或愿望名称。
- 愿望最多三个，支持新增、编辑、删除确认，进度为已有金额加创建后的新增预估收入；累计使用共享 `earnedBetween` 区间计薪并跨午休处理。
- 木鱼支持点击、空格、会话功德、自动敲击和可选短促音效；自动敲击只在工作中、木鱼页可见且应用未离开时运行。
- 隐私模式同步遮蔽首页、愿望、战报金额和进度；编辑愿望金额前要求先显示金额。
- 设置新增工作提醒、主题模式、六位十六进制染色和清除设置并重置；Windows 不模拟 macOS 液态玻璃。
