# 当前与本年预估收入验证

日期：2026-11-05。范围：本次增量功能，不替代首版安装、登录启动、8 小时稳定性或资源预算验收。

## 已确认口径

- 原生 macOS 和 Tauri 前端展示“当前已赚”（原有本班预估金额）和“本年预估已赚”。
- 本年金额从本地一月一日零点累计到当前时刻，按当前工资和排班回算；修改设置后重新估算全年，不表示真实历史到账。
- 跨年班次只将本年发生的计薪部分计入年度金额，月薪仍按班次开始月份折算。
- 隐私开关同时隐藏两个金额；未配置时两个金额为空；休息日保留年度金额。
- 不新增账本、配置字段或第三方依赖；年度回算按月汇总完整班次，只展开跨年班及最近两天。菜单栏继续显示当前班次金额。
