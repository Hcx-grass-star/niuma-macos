# 倒计时与菜单栏

2026-11-06。本次功能扩展以本文替代旧需求中“不展示倒计时”的限制，其余工资计算规则继续沿用。

用户可从收入面板的“倒计时”或设置页的“倒计时与菜单栏”进入管理；原生版也支持 ⌘D。离职、放假、自定义是可修改标题的快捷预设，使用用户指定的日期时间；下班使用已保存的每周作息，自动寻找下一次下班，包括跨夜班次、周末。第一期放假目标由用户指定，不自动推断法定假期。

固定事件不要求填写工资；下班事件缺少作息时明确提示。最多保存 20 条，标题为 1–32 个字符。事件可编辑、删除、关闭；只有保存成功才生效，取消保留原配置。过去的固定目标显示“已到达”，不自动删除。到达后的下班事件切换到下一班结束时间。单个排班目标遇到夏令时无效时刻时显示错误，不阻断固定事件。

首页显示最近三条启用事件；管理页列出全部。详情中超过一天显示天、时、分，临近一天显示时、分、秒。固定目标保存为绝对时刻，换时区后仍指向同一个时刻；排班目标按当前系统时区重新解释作息。

菜单栏内容支持仅图标、当前收入、主倒计时、收入与主倒计时。主倒计时可明确选择，也可自动选择最近事件；选中项被删除或关闭后回退到最近的启用项。金额隐藏仍对收入生效，倒计时标题不随金额隐藏。倒计时涉及个人计划时，可切换为仅图标。

宽度支持自动、80/120/180 pt、自定义 60–240 pt。原生 macOS 直接控制状态栏项目总宽度，包含图标。窄宽度优先保留时间，先缩短标题，再在必要时省略秒；收入与倒计时同时显示且放不下时优先倒计时。完整内容在悬停提示中保留。菜单栏超过一天按剩余整天向上取整，临近一天显示时分秒。

Tauri macOS 通过托盘标题展示，按所选宽度压缩文本；托盘公开 API 未在本次使用中提供精确总宽度控制，实际占位由系统决定。Windows 通过悬停提示和托盘菜单展示内容，无菜单栏文本和固定宽度保证。两项需在对应原生运行环境继续验收。

收入和倒计时共用一个刷新调度器。仅图标且面板关闭时无收入或倒计时刷新任务；可见的近一天目标最多每秒更新，长目标最多每分钟更新；工作中可见收入复用秒级任务。已到达固定事件不再安排倒计时刷新。配置只在用户保存时写入，不保存每秒快照，不为每个事件创建 Timer。原生版响应唤醒、时钟和时区通知；Tauri 重新显示和聚焦时立即重算，隐藏窗口是否可靠暂停及睡眠恢复仍需原生验证。

原生配置位于应用配置目录内的 `countdowns.json`，与 `settings.json` 分开；Tauri 使用 `niuma.countdowns.v1`。旧配置没有新文件或新存储项时，沿用旧收入显示偏好和自动宽度，不清空工资。重置原生设置也会删除应用拥有的倒计时文件。

