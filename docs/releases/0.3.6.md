# 牛马上班 0.3.6

## 更新内容

- 固定日期倒计时到期后自动删除，重新打开应用也会清理已过期的启用项。支持原生 macOS 和 Tauri 共用前端。
- 已完成主倒计时删除后自动选择剩余事件；全部完成时收起倒计时区域。关闭的记录保留，循环下班继续寻找下一班。
- 隐藏面板时只等待最近到期目标，不新增逐秒后台轮询；删除失败时保留原配置并提示。
- 原生 macOS 新增上班、非计薪休息开始/结束及下班提醒，默认关闭，保存开启后请求系统通知权限；通知不包含工资金额。
- 原生收入面板优化上班前、休息和下班后的状态文案。

## 验证与交付范围

- 收入、倒计时、配置保存重载和更新源 HTTP 集成验证通过。
- AppKit 到期删除、菜单栏回退、旧配置兼容、面板和设置交互检查通过。通用 UI 首次运行在再次打开面板处失败，带焦点诊断复跑通过；不将单次通过作为长期稳定性证明。
- 浏览器验证了 Tauri 共用前端到期删除、刷新后不恢复、存储失败提示与恢复路径。
- macOS 提供 arm64 / x86_64 通用包，沿用 ad-hoc 签名，未进行 Apple Developer ID 公证。
- Windows 安装器由对应源码的 GitHub Actions 构建；Windows/Intel/旧版 macOS 真机、真实通知权限与长时运行尚未完成验收。

源码归档分支：`release/0.3.6`；发布标签：`v0.3.6`；原生构建号：`10`。
