# 牛马上班 0.4.3

本次版本继续对齐 Windows/Tauri 与 macOS 的收入面板视觉，复刻 macOS 版的窄窗口构图与透明玻璃布局。

## 更新内容

- 调整 Windows 前端窗口上下留白，使标题区、收入面板和底部操作区与 macOS 版保持同一构图。
- 调整面板横向视觉边界，使收入卡片、导航和底部按钮与 macOS 版截图对齐。
- 保留 Windows 透明玻璃、Mica/Acrylic、四页打气功能和金额隐私遮罩。

## 验证与范围

- `npm run test:core` 通过。
- `bash scripts/test-cheer-ui.sh` 通过。
- 浏览器 434×903 视口验证收入页、木鱼页、木鱼点击和金额隐藏通过。
- 当前环境未执行 Windows 10/11 真机安装包构建和 Mica/Acrylic 真机验收。
